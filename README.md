# Qwikko

QR code generator + branded smart links (`qwikko.com/x/abc123`) with click/scan analytics.

## Stack
- Next.js (App Router) — hosted on Vercel free tier
- Supabase — link storage + click logs
- `qrcode` — client-side QR generation
